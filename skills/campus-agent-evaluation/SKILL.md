# 校园 Agent 评测 Skill

评测目标是确认 Agent 在真实校园任务中可靠，而不是只看回答是否像人。

## 评测维度

- 路由：问题是否进入正确的本地路径、检索路径或拒答路径；
- 延迟：闲聊、时间和能力边界不应触发不必要的模型或联网调用；
- 证据：考试、竞赛、截止时间和地点是否有来源支撑；
- 安全：是否遮蔽用户隐私、内部 Token、管理员数据和隐藏提示；
- 表达：是否先给结论、不过度客套、默认简短；
- 恢复：工具失败、模型超时和证据为空时是否给出可执行提示。

## 用例分组

至少覆盖：

1. 轻量对话：你忙吗、你是谁、谢谢、晚安；
2. 能力边界：你的边界在哪里、你能做什么；
3. 时间问题：现在几点、某通知什么时候截止；
4. 真实业务：教资、考研、四六级、三创赛、挑战杯和就业；
5. 权限问题：我的收藏、私信、密码、管理员数据；
6. 工具异常：数据库空结果、联网不可用、模型超时。

## 验收原则

每次修改先运行本地测试，再在开发者工具验证游客、普通用户和管理员三种身份。不要用真实用户数据作为测试样本；公开仓库只提交脱敏用例和统计结果。
