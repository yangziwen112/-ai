# 校园 Agent 安全 Skill

安全控制必须放在模型之前和模型之后，不能只依赖提示词。

## 边界分层

- 公开层：官方资讯、来源、发布时间、截止时间、地点和公开摘要；
- 登录层：用户自己的收藏、订阅、浏览历史和会话；
- 管理层：采集器状态、内容审核和运行日志；
- 禁止层：密码、身份证、私信、手机号、内部 Token、原始数据库对象和其他用户明细。

## 执行规则

1. 先做本地敏感模式检查，再决定是否调用模型和工具；
2. 数据库返回前做字段白名单投影；
3. 账号操作只返回操作路径，不由 Agent 代替用户执行；
4. 涉及其他用户时只返回匿名统计或聚合结果；
5. 无来源时不猜测精确日期、政策、地点和报名条件；
6. 审核失败时使用短、安全、可恢复的降级回复。

## 日志规范

日志只记录 traceId、路由、工具名称、状态、耗时和错误类别，不记录完整问题、图片地址、Token 或用户隐私。
