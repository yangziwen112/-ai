# 校园来源治理 Skill

这个 Skill 是采集器和 RAG 之间的质量闸门。

## 四层治理

1. 来源层：只允许 HTTPS、可识别官方域名或管理员确认的来源。
2. 内容层：清除脚本、导航、重复段落和无关会议新闻，保留正文和行动项。
3. 时效层：计算 `freshnessScore`，区分已过期、仍有效和未来事项。
4. 权限层：只向 AI 暴露公开资讯投影，不暴露用户、密码、身份证、私信和内部 Token。

## 去重与更新

使用来源标识加 URL 哈希作为 `externalId`，使用正文哈希识别跳过、更新和新增。相同事项的新版本保留最新正文，并可通过 `revisionOf` 关联旧版本。

## 不确定性

没有明确来源、时间或报名入口时，不得补写推测内容。将证据分数降低并在摘要中提示用户核验原文。
