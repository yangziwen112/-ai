# 小程序 UI 与交互规范

- 首页只保留校园聚合平台核心入口：官方资讯、校园动态、二手书、AI 助手和个人中心；管理员入口仅在管理员登录后显示。
- 帖子列表使用统一卡片、来源、时间、摘要和状态标签；详情页提供清晰返回按钮、收藏、分享和登录引导。
- 游客可以浏览公开内容，AI 最多体验三次；点击私有内容时，用“登录后可查看/继续操作”说明原因并提供登录按钮。
- 聊天页按 `conversationId` 保存消息，支持新建和切换历史会话；长文本限制长度、分段显示，用户气泡靠右且不被安全区裁切。
- 二手发布使用明确标签输入：数量、新旧程度、位置、交易方式、原因，并强制实物图；不要与普通帖子共用模糊字段。
- 所有按钮检查安全区、底部 TabBar 和键盘顶起后的布局，避免“发布”按钮覆盖标签或内容。
- 图片加载失败显示占位图和重试，不引用 `127.0.0.1`、临时调试地址或失效外链。
