# 真实采集器规范

采集器应在云函数中运行，来源由管理员配置并记录抓取时间。当前项目可维护的真实来源包括民大官网、教务通知、信息工程学院通知和国家教师资格考试网；竞赛来源应逐个登记官方 URL。

处理链：请求 → robots/频率限制 → HTML 清洗 → 标题/正文/发布时间抽取 → AI 摘要 → 分类与标签 → URL 去重 → 内容审核 → 写入 `contents`。摘要必须概括全文重点、对象、时间和行动项，不能简单截取开头几段。

采集失败返回 `CRAWLER_INTERNAL_ACCESS_DENIED`、超时或来源错误，不填充演示数据。所有内部调用校验 `CRAWLER_INTERNAL_TOKEN`，采集器密钥只放云函数环境变量。管理员页面提供“更新教资、更新民大主页、更新竞赛、更新信息工程学院”独立按钮，并显示最近运行状态。

发布前过滤 `example.com`、`example.edu`、`picsum.photos`、localhost、127.0.0.1 和旧演示年份；清理演示数据时只删除明确匹配项，不清空用户内容。
