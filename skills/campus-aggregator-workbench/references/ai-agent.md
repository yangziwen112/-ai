# AI 多智能体与数据权限

推荐使用 LangGraph 编排四步工作流：

1. 意图识别：区分校园资讯、时间查询、二手交易、视频处理和闲聊。
2. 路由与检索：只调用该意图允许的工具，读取数据库公开投影并进行 RAG 检索。
3. 生成：根据来源、时间和用户身份生成简洁答案，优先列出结论和官方链接。
4. 审核与反思：检查事实、时效、隐私泄露、越权字段和过长表达；失败则重写或明确说明无法确认。

工具层至少包括服务器时间、官方站点搜索、受控数据库查询、RAG 检索和视频转写。每个工具都要有参数白名单、超时、重试和审计日志。数据库查询返回 DTO 投影，不返回手机号、内部 Token、管理员字段或完整原始文档。

回答风格：短句、分点、少套话；时间问题给出时区和来源；不确定时说“不确定”并给出核验入口。新会话不能覆盖旧会话，游客额度由服务端计数。
