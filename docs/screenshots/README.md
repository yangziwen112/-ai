# 产品页面截图

这里保留的是小程序产品页面截图，用于帮助学习者理解页面结构和交互重点。截图不包含微信开发者工具窗口、调试面板、个人账号、云环境标识或任何凭证。

| 页面 | 说明 |
|---|---|
| [首页](01-home.png) | 展示官方资讯、近期事项、分类入口和 AI 助手入口，说明平台如何把校园信息集中到首屏 |
| [校园动态](02-campus-feed.png) | 展示官方资讯、校园交流和二手闲置的分层呈现，避免不同内容混成同一种帖子 |
| [AI 助手](03-ai-chat.png) | 展示新建会话、短答案、头像动画和折叠参考资料，说明回答先解决问题再提供佐证 |
| [管理中心](04-admin-center.png) | 展示教资、考研、竞赛、学院和就业等分组采集入口，说明管理员可以按业务更新数据 |
| [消息](05-messages.png) | 展示登录后的私信入口和游客登录引导，说明个人消息与公开资讯保持权限边界 |
| [个人中心](06-profile.png) | 展示收藏、订阅、历史、设置和管理员入口，说明需要登录的功能集中管理 |

截图只用于说明产品界面，不代表线上数据的实时状态。真实考试、竞赛和校园通知仍应以平台中的来源链接和官方原文为准。
