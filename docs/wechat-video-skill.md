# 微信视频号内容处理 Skill

本 Skill 将视频号分享链接或作品标识转换为可检索的内容资料：获取详情、下载加密媒体、使用匹配密钥解密、在本地转写语音，并在没有语音时识别画面字幕。

## 输入与输出

输入支持分享短链、作品 ID 或导出 ID，按可靠性排序选择一个。输出目录包含脱敏的视频详情 JSON、Markdown 详情、转写文本、字幕文件和已验证的本地视频。大整数 ID 按字符串处理。

## 安全边界

具体服务地址和密钥不写入 Skill 或公开文档，由本地适配器从环境变量读取。媒体地址令牌和解密密钥只在内存或受保护的临时目录中使用，完成后清理；最终报告不输出这些值。仅处理拥有授权的内容，并遵守平台版权规则。

## 处理要点

- 网络请求设置足够的超时并避免重复计费请求。
- 下载媒体和解密密钥必须来自同一次详情响应。
- 本地转写默认使用 faster-whisper，模型可按设备能力选择。
- 转写结果需标注来源（语音或画面文字），并允许人工复核。

实现时优先复用本机的 `wechat-latest-video-transcriber` Skill，不在小程序前端直接请求第三方服务。
