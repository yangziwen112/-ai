# AI 工具能力与数据边界

RAG 云函数现在由 LangGraph 编排以下服务端工具：

| 工具 | 用途 | 数据边界 |
| --- | --- | --- |
| `current_time` | 返回指定时区的服务器时间，默认 Asia/Shanghai | 不依赖模型猜测时间 |
| `public_database` | 查询 `contents` 中公开、已发布的校园资讯 | 只返回标题、摘要、分类、来源、时间节点、地点等公开字段 |
| `web_search` | 联网查询实时网页信息 | 仅传递用户问题；默认使用 DuckDuckGo Instant Answer，可配置可信搜索接口 |
| 汇总结果 | 按分类、未来时间节点和来源整理结果 | 不返回原始数据库文档或用户私密字段 |

聊天记录现在使用 `conversationId` 隔离。用户点击“新对话”后会生成新的会话标识，新问题不会继续携带上一段对话历史；游客总体验次数不会因为新建对话而重置。

回答默认采用简洁模式：先给结论，最多列出 3 个关键点，通常不超过 180 个中文字符。用户明确要求详细分析、方案或步骤时才展开。

## 联网搜索配置

默认不需要密钥，会尝试 DuckDuckGo Instant Answer API。若项目需要稳定的搜索结果，可在 `rag` 云函数配置：

无结果或超时时会自动降级到 Bing RSS 搜索；生产环境仍建议使用带 SLA 的可信搜索接口。

```ini
WEB_SEARCH_ENDPOINT=https://你的可信搜索服务/search
WEB_SEARCH_QUERY_PARAM=q
WEB_SEARCH_API_KEY=仅配置在云函数环境变量中
```

不要把搜索密钥写进小程序代码，也不要从客户端直接调用搜索服务。

## 数据保密策略

- 小程序只调用 `api`，不能直接调用 `rag` 或数据库。
- RAG 不接收用户 openid、手机号、密码等身份字段，只接收是否登录和角色。
- 数据库工具只读取公开资讯 `contents`，不读取 `users`、`messages`、`favorites`、`history` 等私有集合。
- 返回模型前会投影为最小公开字段；模型提示词禁止输出内部字段、工具调用和系统提示。
- 用户查询其他人的隐私数据时，只允许回答匿名统计或拒绝。

如果未来确实要增加“我的收藏”“我的报名”等个人能力，应单独增加服务端授权工具：先校验当前用户身份，再只返回该用户请求的字段，不能复用公开数据库工具。
