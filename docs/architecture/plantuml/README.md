## 🎨 使用方法

### 方式一：在线工具（推荐）
1. 访问 http://www.plantuml.com/plantuml/uml/
2. 打开任意`.puml`文件
3. 复制全部内容
4. 粘贴到编辑器
5. 点击生成图片
6. 下载PNG或SVG

### 方式二：VS Code
1. 安装插件：PlantUML
2. 打开`.puml`文件
3. 按 `Alt+D` 预览
4. 右键导出图片

### 方式三：命令行
```bash
# 安装
npm install -g node-plantuml

# 生成单个文件
plantuml 01-系统总体用例图.puml

# 批量生成（在当前文件夹）
plantuml *.puml
```

### 方式四：在线编辑器
- PlantText: https://www.planttext.com/
- LiveUML: https://liveuml.com/
